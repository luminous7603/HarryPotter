해리 포터 세계의 마법은 라틴어 또는 라틴어 파생 주문으로 구성됩니다. 지팡이 동작과 주문을 함께 사용해야 합니다.

## 방어 주문

| 주문 | 효과 |
|------|------|
| **엑스펠리아무스** | 상대방의 지팡이를 날려버림 (무장 해제) |
| **프로텍토** | 방어막 생성 |
| **익스펙토 패트로눔** | 수호신 소환, 디멘터 퇴치 |
| **스투페파이** | 상대방을 기절시킴 |

## 공격 주문

| 주문 | 효과 |
|------|------|
| **아바다 케다브라** | 저주할 수 없는 죽음의 주문 |
| **크루키아투스** | 극심한 고통 유발 |
| **임페리우스** | 상대방을 완전히 지배 |

## 일반 주문

| 주문 | 효과 |
|------|------|
| **루모스** | 지팡이 끝에 빛 생성 |
| **알로호모라** | 잠긴 문 열기 |
| **레비오사** | 물체 공중 부양 |
| **수마모** | 수리/복구 마법 |
